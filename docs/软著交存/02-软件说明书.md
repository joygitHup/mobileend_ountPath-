## 软件说明书（V1.0）

**软件全称：** 山途徒步智能决策与安全保障系统  
**软件简称：** 山途  
**版本号：** V1.0  

---

## 第 1 章 概述

### 1.1 编写目的

本说明书用于说明「山途」系统的功能组成、运行环境、安装部署与主要操作流程，供用户使用、测试验收及软件著作权登记文档鉴别材料使用。

### 1.2 软件简介

山途是面向徒步爱好者的智能决策与安全保障软件系统。系统帮助用户在行前了解路线与准备清单，在行中进行行程管理与守护相关操作，并通过社区进行路况交流与约伴；同时为运营人员提供内容审核、行程与安全事件管理能力。

系统由三部分组成：

1. **移动客户端（App）**：面向终端用户，运行于 iOS / Android（基于 Expo / React Native）。
2. **业务后端服务（mobileback）**：提供鉴权、路线、行程、清单、社区、守护、轨迹等 REST API。
3. **运营管理台（mobilemange）**：面向运营人员的 Web 管理界面。

### 1.3 术语

| 术语 | 说明 |
|------|------|
| 路线 | 可供选择的徒步线路信息，含难度、里程、风险相关展示等 |
| 行程 | 用户针对某条路线创建的出行计划与执行状态 |
| 准备清单 | 按路线生成的装备/事项勾选列表 |
| 守护 | 行中安全相关能力，含开始/结束守护、打卡、SOS 等流程 |
| 约伴 | 社区中发起或加入同行邀约的功能 |
| 轨迹 | 用户步行过程中的路径记录与参考 |

## 第 4 章 安装与启动（开发/演示）

### 4.1 获取源码

从项目仓库获取完整源码（monorepo），主要目录：`client/`、`mobileback/`、`mobilemange/`。

### 4.2 启动后端

```bash
cd mobileback
make seed    # 导入 seeds/*.json 演示数据
make run     # 启动 API，默认 :9092
```

演示登录验证码一般为 `1234`（以种子与 README 为准）。

### 4.3 启动移动客户端

配置环境变量指向后端，例如：

```bash
EXPO_PUBLIC_BACKEND_BASE_URL=http://127.0.0.1:9092
```

在仓库约定方式下启动 Expo 开发服务（如 `pnpm --filter expo-app start` 或项目文档所述命令），使用模拟器或真机预览。

### 4.4 启动运营管理台

```bash
pnpm install          # 仓库根目录
pnpm dev:admin        # 默认 http://127.0.0.1:9093
```

演示管理员账号以 `mobileback` 种子数据为准（例如具备 `role=admin` 的手机号用户）。

## 第 5 章 移动客户端操作说明

### 5.1 启动与登录

1. 打开应用，进入启动页后到达登录页。
2. 输入手机号，获取验证码（演示环境可按提示使用固定验证码）。
3. 登录成功后进入底部导航：首页、行程、社区、我的。

### 5.2 发现路线并查看详情

1. 在首页浏览推荐路线或使用搜索。
2. 点击路线卡片进入路线详情。
3. 查看里程、难度、风险/评分等相关信息。
4. 可执行收藏、加入行程等操作（需登录）。

### 5.3 创建行程与准备清单

1. 从路线详情加入行程，或在行程页查看当前行程。
2. 进入智能准备清单，按分类勾选装备与事项。
3. 清单完成后可按界面引导进入守护或返回行程。

说明：部分流程要求「已有行程」后方可继续（例如清单强依赖行程场景），请按界面提示操作。

### 5.4 行中守护与 SOS

1. 在守护页开始守护（按权限提示授权定位）。
2. 可进行位置打卡等行中操作。
3. 紧急情况下可发起 SOS；事后可通过「结束上报 / 确认安全」等入口收口。
4. 安全中心可维护紧急联系人与安全相关设置。

### 5.5 轨迹记录

1. 进入轨迹相关页面，开始记录。
2. 结束记录时提交结束信息（含里程等相关数据，以后端接口为准）。
3. 中途退出时按界面提示确认，避免数据丢失。

### 5.6 社区与约伴

1. 在社区浏览帖子、路况或约伴信息。
2. 可发帖、评论、点赞。
3. 对约伴帖可申请加入；按提示填写/确认行程相关信息后完成加入流程。

### 5.7 个人中心

1. 查看与编辑个人资料。
2. 进入消息列表查看通知。
3. 打开法律文档、隐私相关页面了解协议内容。

## 第 6 章 运营管理台操作说明

### 6.1 登录

使用具备管理员角色的账号登录管理台。未授权或令牌失效时应重新登录。

### 6.2 仪表盘

查看关键运营概况，并通过入口跳转到用户、安全、行程、社区等子模块。

### 6.3 内容与业务管理

| 模块 | 典型操作 |
|------|----------|
| 路线 | 查看/编辑路线信息、评分相关字段、上下架或发布状态 |
| 轨迹 | 查看轨迹数据、表单维护 |
| 清单 | 维护路线对应清单项 |
| 行程 | 查看用户行程、必要时强制结束等运营动作 |
| 社区 | 帖子与评论管理、约伴相关状态 |
| 用户 | 用户列表与角色相关查看 |
| 安全 | SOS / 守护相关值守、结案处理 |
| 系统 | 系统配置、法律文档段落等 |

具体字段以管理台表单为准；操作成功后移动端通过 API 拉取最新数据。

## 第 7 章 主要业务流程

### 7.1 行前准备闭环

```
选路线 → 加入行程 → 勾选准备清单 →（可选）设置联系人 → 出发提醒/进入守护
```

### 7.2 行中安全闭环

```
开始守护 → 打卡/跟线示意 →（异常）SOS → 通知链路 → 确认安全 / 运营结案
```

### 7.3 社区协作闭环

```
发帖/约伴 → 浏览与互动 → 申请加入 → 关联行程 → 后续出行
```

### 7.4 运营治理闭环

```
内容上架 → 用户使用 → 安全事件进入值守台 → 处理结案 → 审计留痕
```

## 第 8 章 数据与安全说明

### 8.1 账号与鉴权

移动端与管理台通过后端签发的令牌访问受保护接口。演示环境验证码固定，生产环境应接入真实短信等能力并轮换密钥。

### 8.2 位置与隐私

定位权限用于守护、打卡与 SOS 等场景。应用内提供隐私政策与用户协议入口。上架与商用前应完善隐私合规、权限最小化与数据留存策略。

### 8.3 演示能力边界

部分能力在演示版本中为示意实现（例如部分通知、跟线精度等）。说明书描述以当前产品流程为准；生产加固项见工程内集成文档。

## 第 9 章 异常与常见问题

| 现象 | 可能原因 | 处理建议 |
|------|----------|----------|
| 无法登录 | 后端未启动或验证码错误 | 确认 :9092 可用，使用正确验证码 |
| 列表空白 | 未 seed 或接口失败 | 执行 `make seed`，检查网络与 Base URL |
| 守护无法定位 | 未授权定位权限 | 在系统设置中开启定位 |
| 管理台 401 | 非管理员或令牌过期 | 使用 admin 角色账号重新登录 |
| 清单无法继续 | 无当前行程 | 先从路线加入行程 |
