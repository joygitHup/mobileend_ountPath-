# 软著交存材料包

本目录整理 **山途（MountPath）** 软件著作权登记所需的交存/鉴别材料草稿，可直接据此排版打印或转 PDF 后提交。

## 目录结构

```
docs/软著交存/
├── README.md                      # 本说明
├── 01-登记申请信息.md              # 填表用字段（权利人等信息需自行补全）
├── 02-软件说明书.md                # 软件说明书 / 用户手册（鉴别材料之一）
├── 03-源程序鉴别材料说明.md        # 源程序交存规则与打印要求
├── scripts/
│   └── gen-source-deposit.sh      # 从仓库生成「前 50 页 + 后 50 页」源程序文本
└── output/                        # 脚本生成物（可 gitignore，提交前本地生成）
    ├── 源程序-前50页.txt
    ├── 源程序-后50页.txt
    └── 源程序-合并交存.txt
```

## 官方常见交存要求（摘要）

中国版权保护中心对一般交存的常见要求（以当时官网/代理机构最新说明为准）：

| 材料 | 常见要求 |
|------|----------|
| **源程序** | 按前 30 页 + 后 30 页（或前 50 + 后 50）连续页提交；每页不少于 50 行；不足 60 页可全部提交 |
| **文档** | 软件说明书：前 30 页 + 后 30 页；不足 60 页可全部提交 |
| **页眉** | 建议每页标注：软件全称 + 版本号 |
| **页脚** | 连续页码 |

> 本仓库生成的文本按 **每页 50 行** 切分；打印时用等宽字体（如 Courier / Consolas 9–10pt），A4，保证每页约 50 行。

## 推荐使用流程

1. 补全 `01-登记申请信息.md` 中的权利人、完成日期、首次发表日期等。
2. 核对 `02-软件说明书.md` 功能描述与当前产品一致；按需增删截图说明（截图可另附）。
3. 在仓库根目录执行：

```bash
bash docs/软著交存/scripts/gen-source-deposit.sh
```

4. 打开 `output/` 中的文本，用 Word/WPS 设页眉页脚后导出 PDF，与说明书一并交存。
5. 若总页数不足 60，可只交「合并交存」全文；超过则交「前 50 页 + 后 50 页」。
