## 4. 软件功能与特点（申请表「简述」可用）

**功能简述（约 200 字内）：**

本软件面向徒步场景，提供路线发现与详情（含难度与风险相关展示）、行程与智能准备清单、行中位置相关守护与 SOS 求助流程、轨迹记录参考、社区约伴与内容互动，以及用户资料与安全中心配置；服务端提供鉴权、业务 API 与数据持久化；另含运营管理端，支持路线/行程/社区/安全事件等运营操作。

**技术特点：**

- 移动端采用 Expo / React Native 跨平台实现；
- 服务端采用 Go + Gin，本地默认 SQLite，REST API 对接移动端；
- 运营管理台采用 Vite + React，对接管理端 API；
- 业务覆盖「行前准备—行中守护—社区协作—后台运营」闭环。
