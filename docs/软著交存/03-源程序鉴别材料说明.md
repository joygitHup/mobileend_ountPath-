# 源程序鉴别材料说明

## 1. 交存范围

本软件源程序鉴别材料从下列目录抽取连续代码文本（排除依赖、构建产物、锁文件与二进制）：

| 优先级 | 路径 | 说明 |
|--------|------|------|
| 高 | `mobileback/cmd/`、`mobileback/internal/` | 后端核心 |
| 高 | `client/app/`、`client/screens/`、`client/contexts/`、`client/hooks/`、`client/utils/`、`client/components/`（不含大型 UI 库拷贝） | 客户端业务 |
| 中 | `mobilemange/src/` | 运营管理台 |

默认脚本会 **跳过** `node_modules`、`client/heroui`（组件库文档与实现拷贝体量大）、`.pnpm-store`、`dist`、`build`、`.git`、`*.lock` 等。

## 2. 生成方式

在仓库根目录执行：

```bash
bash docs/软著交存/scripts/gen-source-deposit.sh
```

生成文件位于 `docs/软著交存/output/`：

| 文件 | 用途 |
|------|------|
| `源程序-全部连续.txt` | 按文件顺序拼接的全部入选源码 |
| `源程序-前50页.txt` | 前 50×50 行 |
| `源程序-后50页.txt` | 后 50×50 行 |
| `源程序-合并交存.txt` | 若总页数 ≤100：等于全部；否则为「前 50 页 + 分隔说明 + 后 50 页」 |
| `源程序-页数统计.txt` | 总行数、估算页数、入选文件列表 |

每页按 **50 行** 估算（符合常见「每页不少于 50 行」的排版习惯）。

## 3. 打印 / PDF 要求

1. 等宽字体，字号约 9–10pt，行距紧凑，保证每页约 50 行。
2. **页眉**：`山途徒步智能决策与安全保障系统 V1.0`（与申请表全称、版本一致）。
3. **页脚**：连续页码。
4. 不要添加语法高亮色块（黑白打印即可）。
5. 源程序中的注释、空行可保留；勿手工删改业务逻辑行导致与仓库不一致。

## 4. 页数不足或过多时

| 情况 | 处理 |
|------|------|
| 总页数 ≤ 60 | 可提交 `源程序-全部连续.txt` 全文 |
| 总页数 > 60 | 提交前 50 页 + 后 50 页（或登记机关要求的前 30+后 30） |
| 代理机构要求仅客户端 | 修改脚本中的 `INCLUDE_DIRS` 后重新生成 |

## 5. 注意

- `output/` 为生成物，体积可能较大；默认写入 `.gitignore`，交存前本地生成即可。
- 交存文本为 **鉴别用节选**，不等于完整开源授权发布。
- 若代码含密钥、内网地址，打印前请脱敏（脚本不会自动删除业务代码中的字符串常量）。
